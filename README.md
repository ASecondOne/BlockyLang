# Blocky Lang

A small experimental language and interpreter written in Rust. The user-facing language guide is in [`docs/README.md`](docs/README.md), and a runnable tour of the current language is in [`test_foulder/src/main.block`](test_foulder/src/main.block).

Build and run the sample project from the repository root:

```bash
cargo build
cd test_foulder
../target/debug/blocky_lang run
```
